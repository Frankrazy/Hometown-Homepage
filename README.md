# Hometown Homepage

A vibrant static travel landing page celebrating Lodwar, Turkana, Kenya. The project showcases the town's cultural heritage, natural beauty, local experiences, and hospitality in a visually engaging layout.

## Overview

This homepage is designed as a simple tourism-style landing page for a hometown or destination promotion project. It uses pure HTML and CSS to present a clean and welcoming travel experience without any external frameworks or build tools.

## Features

- Hero banner with a warm welcome message
- Five highlighted activities to enjoy in Lodwar
- Local image sections with descriptive captions
- Colorful, themed styling inspired by the destination
- Guide section introducing a local host
- Fully static and lightweight setup

## Getting Started

### Open directly in a browser

Open the project folder and launch `index.html` in any modern browser.


## Customization

You can personalize this page by:

- updating the text in `index.html`
- changing colors, spacing, and layout in `styles.css`
- replacing or adding images in the `images/` folder
- expanding the page with extra sections such as testimonials, travel tips, or a map

## Notes

This is a static website, so there are no dependencies to install or build steps required. It is ideal for simple presentation projects, portfolio work, or educational HTML/CSS exercises.
